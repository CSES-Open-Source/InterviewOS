# Notes from LeetCode and NeetCode

Public, signed-out walkthrough on November 9, 2026. This covered problem pages,
hints, topic lists, and a solution visualization, not completed submissions or
paid features. These are references for our hub, not platforms we plan to replace.

| Tool | What worked | What was annoying | What was missing in the flow checked |
| --- | --- | --- | --- |
| LeetCode | Clear examples and hints; question, editor, and test cases together. | A crowded page with ads, statistics, and discussions. Running code required signing in, and company information was locked. | Feedback on explaining an approach to another person and answering their follow-up questions. |
| NeetCode | Problems grouped by topic, several explained approaches, and a step-by-step visualization. | Several lists to choose from, some Pro-only content, and long solution pages. Run/Submit stayed disabled in this check, so execution was not evaluated. | A live partner and feedback on communication within the individual-study flow checked. |

For InterviewOS, the useful part is connecting existing practice to a peer
session. A student can work on a problem on LeetCode, explain the approach in a
mock interview, and save a specific next step from the feedback. The November 9
team discussion clarified that our platform should link out for coding practice.
We should test whether the peer-session and tracking experience is useful before
adding a large original problem library or treating code execution as MVP scope.

Sources: [LeetCode Two Sum](https://leetcode.com/problems/two-sum/),
[NeetCode 150](https://neetcode.io/practice/practice/neetcode150), and
[NeetCode Two Sum solution](https://neetcode.io/problems/two-integer-sum/solution).
